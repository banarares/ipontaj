# Susține dezvoltarea și promovarea iPontaj

Vrem ca iPontaj să ajungă la echipe mici care au nevoie de un pontaj simplu în română. Fondurile pot accelera dezvoltarea, verificarea și găsirea primilor utilizatori. Prioritatea propusă este marketingul măsurabil, împreună cu stabilitatea produsului.

## Canalul preferat: GitHub Sponsors

Beneficiarul propus este profilul GitHub **banarares**, după înrolarea și activarea în GitHub Sponsors. La verificarea din 24 noiembrie 2026, adresa publică de sponsorizare a redirecționat la profilul GitHub și nu a prezentat niveluri de susținere. De aceea nu prezentăm încasările ca active și nu afișăm un buton care pretinde că o plată poate fi făcută deja.

România apare în [regiunile acceptate de GitHub Sponsors](https://docs.github.com/en/sponsors/getting-started-with-github-sponsors/about-github-sponsors). Eligibilitatea individuală, contribuțiile open source, verificarea profilului și datele bancare/fiscale sunt evaluate de GitHub; existența unui repository privat nu constituie singură o activare a profilului.

Pentru activare, titularul urmează [configurarea profilului personal](https://docs.github.com/en/sponsors/receiving-sponsorships-through-github-sponsors/setting-up-github-sponsors-for-your-personal-account), completează datele direct în GitHub și verifică tratamentul fiscal cu contabilul. Nu trimite date bancare, formulare fiscale sau documente de identitate prin issues, pull requests ori conversații publice.

După ce pagina publică funcționează, înlocuiește legătura informativă din `.github/FUNDING.yml` cu:

```yaml
github: [banarares]
```

Verifică apoi pagina de sponsorizare deconectat de la GitHub și documentează beneficiarul, scopul și eventualele beneficii. [GitHub documentează configurarea butonului Sponsor](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/displaying-a-sponsor-button-in-your-repository).

## Propunere de utilizare a fondurilor

Acesta este un plan pentru discuție, nu un buget deja finanțat și nici o promisiune contractuală pentru o campanie activă.

| Direcție                  | Proporție orientativă | Exemple                                                                                                          |
| ------------------------- | --------------------- | ---------------------------------------------------------------------------------------------------------------- |
| Marketing și validare     | 60%                   | Discuții cu echipe și contabili, materiale demonstrative, pagini utile și campanii mici după pregătirea lansării |
| Dezvoltare și verificare  | 30%                   | Erori, accesibilitate, îmbunătățirea fluxurilor și teste pe dispozitive/baze de date                             |
| Infrastructură și operare | 10%                   | Găzduire, email, backupuri și instrumente necesare operării                                                      |

Înainte de cheltuieli reale, responsabilul publică obiectivul, plafonul și criteriul de continuare. Nu cheltuim bugetul de marketing pe promovarea unui checkout care nu este pregătit comercial și fiscal.

## Cum măsurăm marketingul

- Începem cu un segment: echipe mici și contabili care pregătesc lunar pontaje.
- Validăm problema prin discuții și demonstrații pe date fictive, înainte de reclame ample.
- Măsurăm separat înscrierea, configurarea, prima invitație, prima confirmare și revenirea la încheierea lunii.
- Evaluăm costul pentru o echipă care folosește efectiv produsul, nu doar numărul de clickuri.
- Introducem analiză sau publicitate doar după evaluarea GDPR/cookie-urilor, informarea corectă și mecanismele de consimțământ necesare. În prezent aplicația nu include trackere de marketing.

## Transparență

După activarea finanțării, propunem un raport lunar cu soldul inițial, încasări, comisioane, cheltuieli agregate pe categorii, soldul final și rezultatele obținute. Nu publicăm identitatea susținătorilor fără acord, date de plată sau facturi cu informații personale. În prezent nu afirmăm că au fost colectate fonduri.

Susținerea proiectului este distinctă de abonamentul iPontaj. Nu promitem randament financiar, participații, deducere fiscală sau statut de donație caritabilă. O eventuală colaborare comercială pentru promovare, cu prestații sau beneficii, trebuie definită și tratată fiscal potrivit situației sale.

Poți ajuta și fără bani: [contribuții](CONTRIBUTING.md), testare, documentație, accesibilitate sau recomandări relevante. Pentru discuții despre susținere: **office@ipontaj.ro**, subiect „Susținere proiect iPontaj”.
